# บันทึกการลงทุน — Investment Ledger

เว็บไซต์บันทึกการซื้อขายหุ้น ทอง คริปโตเคอร์เรนซี และสินทรัพย์อื่นๆ จากหลายแหล่ง มารวมไว้ที่เดียว
ใช้ Google Sheets เป็นฐานข้อมูล และมี 2 มุมมอง:

- **มุมมองสาธารณะ** (ค่าเริ่มต้น) — ใครก็เห็นได้ แต่เห็นแค่ **ชื่อ + ประเภท + หมวดหมู่** ของสินทรัพย์ ไม่เห็นจำนวนเงิน
- **มุมมองเจ้าของ** — ปลดล็อกด้วยรหัสผ่าน เห็นข้อมูลทุกคอลัมน์ รวมจำนวน ต้นทุน มูลค่าปัจจุบัน และกำไร/ขาดทุน

**สำคัญ:** การกรองข้อมูลเกิดขึ้นที่ฝั่ง Google Apps Script (เซิร์ฟเวอร์) ไม่ใช่การซ่อนด้วย CSS/JavaScript
ฝั่งหน้าเว็บ ดังนั้นข้อมูลจำนวนเงินจะไม่ถูกส่งมาถึงเบราว์เซอร์ของผู้เยี่ยมชมเลย ปลอดภัยกว่าการซ่อนด้วยการแสดงผลเฉยๆ

> ⚠️ หมายเหตุด้านความปลอดภัย: ระบบนี้เหมาะสำหรับ "กันคนทั่วไปเผลอเห็นข้อมูล" ในระดับโปรเจกต์ส่วนตัว/พอร์ตโฟลิโอ
> ไม่ใช่ระบบยืนยันตัวตนระดับธนาคาร รหัสผ่านถูกเก็บเป็นข้อความธรรมดาใน Script Properties และส่งผ่าน HTTPS
> ถ้าต้องการความปลอดภัยสูงขึ้น ควรพิจารณา Google OAuth หรือ Firebase Authentication แทน

## ขั้นตอนที่ 1 — สร้าง Google Sheet

1. สร้าง Google Sheet ใหม่ (ตั้งชื่อไฟล์อะไรก็ได้ เช่น "Investment Data")
2. เปลี่ยนชื่อชีตแผ่นแรก (แถบด้านล่าง) เป็น `Transactions`
3. ใส่หัวตารางในแถวที่ 1 ตามลำดับนี้ (คอลัมน์ A ถึง K):

| A | B | C | D | E | F | G | H | I | J | K |
|---|---|---|---|---|---|---|---|---|---|---|
| วันที่ | ประเภท | ชื่อสินทรัพย์ | หมวดหมู่ | แหล่งที่ซื้อ | จำนวน | ราคาต่อหน่วย | ต้นทุนรวม | มูลค่าปัจจุบัน | สกุลเงิน | หมายเหตุ |

4. ใส่ข้อมูลตัวอย่างในแถวที่ 2 เป็นต้นไป เช่น:

| วันที่ | ประเภท | ชื่อสินทรัพย์ | หมวดหมู่ | แหล่งที่ซื้อ | จำนวน | ราคาต่อหน่วย | ต้นทุนรวม | มูลค่าปัจจุบัน | สกุลเงิน | หมายเหตุ |
|---|---|---|---|---|---|---|---|---|---|---|
| 2026-01-15 | หุ้น | PTT | พลังงาน | บล. XYZ | 500 | 35.00 | 17500 | 18200 | THB | |
| 2026-02-03 | ทอง | ทองคำแท่ง 96.5% | ทองคำแท่ง | ร้านทอง ABC | 2 | 42000 | 84000 | 86500 | THB | ทองคำหนัก 2 บาท |
| 2026-03-10 | คริปโต | BTC | Store of value | Binance | 0.05 | 1400000 | 70000 | 75000 | THB | |
| 2026-04-01 | หุ้น | AMZN | อีคอมเมิร์ซและคลาวด์ | Dime | 0.0778 | 233.03 | 18.12 | | USD | |

**ประเภท (คอลัมน์ B) ต้องพิมพ์ตรงกับตัวเลือกในเว็บ:** `หุ้น`, `ทอง`, `คริปโต`, หรือ `อื่นๆ`

**สกุลเงิน (คอลัมน์ J):** ใส่ `USD`, `THB`, `EUR`, `GBP`, หรือ `JPY` — ถ้าเว้นว่างไว้ระบบจะถือว่าเป็น `THB` โดยอัตโนมัติ
เว็บจะแสดงสัญลักษณ์สกุลเงินให้ถูกต้องต่อรายการ (เช่น หุ้นสหรัฐขึ้น `$` ทองคำไทยขึ้น `฿`) และจะ **แยกยอดรวมในแถบสรุปตามสกุลเงิน**
โดยอัตโนมัติ (เช่น "ลงทุนรวม (USD)" กับ "ลงทุนรวม (THB)" แยกกัน) เพราะการรวมข้ามสกุลเงินโดยไม่แปลงอัตราแลกเปลี่ยนจะให้ตัวเลขที่ผิด

ทุกครั้งที่ซื้อขายเพิ่ม แค่เพิ่มแถวใหม่ในชีตนี้ — เว็บจะดึงข้อมูลล่าสุดทุกครั้งที่โหลดหน้า

## ขั้นตอนที่ 2 — ติดตั้ง Apps Script (ตัวกรองข้อมูล)

1. ใน Google Sheet เดิม ไปที่เมนู **Extensions → Apps Script**
2. ลบโค้ดเริ่มต้นทั้งหมดในไฟล์ `Code.gs` ที่เปิดขึ้นมา แล้ว **คัดลอกโค้ดทั้งหมดจากไฟล์ `Code.gs`** ที่แนบมาวางแทน
3. แก้บรรทัดนี้ในฟังก์ชัน `setOwnerKey()` ให้เป็นรหัสผ่านที่คุณต้องการ:
   ```js
   const myPassword = "เปลี่ยนรหัสผ่านตรงนี้";
   ```
4. ที่แถบด้านบน เลือกฟังก์ชัน `setOwnerKey` จาก dropdown แล้วกด **▶ Run** (ครั้งแรกจะขอสิทธิ์การเข้าถึง กด Allow)
   — รันครั้งเดียวพอ นี่คือการ "ตั้งรหัสผ่าน" ให้ระบบจำไว้
5. กด **Deploy → New deployment**
   - Select type: **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - กด **Deploy** แล้วกด **Authorize access** ตามที่ระบบขอ
6. คัดลอก **Web app URL** ที่ได้ (จะขึ้นต้นด้วย `https://script.google.com/macros/s/.../exec`)

## ขั้นตอนที่ 3 — เชื่อมเว็บกับ Apps Script

1. เปิดไฟล์ `script.js`
2. แก้บรรทัดบนสุด:
   ```js
   const APPS_SCRIPT_URL = "PASTE_YOUR_APPS_SCRIPT_WEB_APP_URL_HERE";
   ```
   แทนที่ด้วย URL ที่คัดลอกมาจากขั้นตอนที่ 2
3. บันทึกไฟล์

---

## ขั้นตอนที่ 4 — เปิดดูบนเครื่องตัวเอง (ทดสอบก่อนอัปโหลด)

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย หรือถ้าต้องการรันผ่าน local server (แนะนำ เพราะบางเบราว์เซอร์บล็อก fetch จากไฟล์ local):

```bash
cd investment-ledger
python3 -m http.server 8000
```

แล้วเปิด `http://localhost:8000`

---

## ขั้นตอนที่ 5 — อัปโหลดขึ้น GitHub Pages

1. สร้างโฟลเดอร์ใหม่ในรีโปของคุณ (หรือสร้างรีโปใหม่แยกต่างหาก เช่น `investment-ledger`)
2. อัปโหลดไฟล์ `index.html`, `style.css`, `script.js` (ไม่ต้องอัปโหลด `Code.gs` เพราะมันอยู่ใน Google Sheet แล้ว)
3. ไปที่ **Settings → Pages** ของรีโป เลือก branch ที่ต้องการ deploy
4. รอสักครู่ จะได้ลิงก์ เช่น `https://noppawit1480-byte.github.io/investment-ledger/`
5. กลับไปที่เว็บ Portfolio หลัก ([noppawit1480-byte.github.io/Portfolio](https://noppawit1480-byte.github.io/Portfolio/)) แล้วเพิ่มการ์ดผลงานลิงก์ไปยังเว็บนี้

## การใช้งานประจำวัน

- **เพิ่มรายการซื้อขาย** → เปิด Google Sheet เพิ่มแถวใหม่ในชีต `Transactions`
- **ดูมุมมองเจ้าของ** → กดปุ่ม "เข้าสู่ระบบเจ้าของ" มุมขวาบน ใส่รหัสผ่านที่ตั้งไว้
- **เปลี่ยนรหัสผ่าน** → กลับไปแก้ใน Apps Script แล้วรัน `setOwnerKey()` ใหม่อีกครั้ง

## แนวคิดการออกแบบ

ธีม "สมุดบัญชีเก่า/ห้องนิรภัย" — พื้นหลังกรมท่าเข้มมีเส้นบรรทัดจางๆ แบบกระดาษบัญชี ตัวเลขใช้ฟอนต์ mono
เพื่อให้อ่านง่ายและดูน่าเชื่อถือแบบข้อมูลการเงินจริง สีทองเป็นสีหลักเพราะเป็นทั้งสีของสินทรัพย์ทองคำและ
สื่อถึงความมีค่าของข้อมูล ปุ่มเข้าสู่ระบบเจ้าของออกแบบให้รู้สึกเหมือนกำลังไขห้องนิรภัย เพื่อสื่อว่าข้อมูล
ด้านในเป็นเรื่องส่วนตัว
